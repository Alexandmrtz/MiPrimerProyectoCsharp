📘 Descripción

Este proyecto representa mi entrega final del ciclo II, desarrollada con esfuerzo y dedicación. El código y las distintas ramas del repositorio muestran mis aportes, avances, errores, correcciones y aprendizajes durante esta etapa.

El sistema tiene como objetivo servir como base funcional de una aplicación completa, con backend y frontend, que pone en práctica los conocimientos adquiridos: estructura de base de datos, lógica en C#, interfaz web, manejo de datos, reportes y formularios.

Más allá de cumplir requisitos académicos, este proyecto refleja mi compromiso de aprender, mejorar y crecer como desarrollador — aun viniendo del trabajo en las noches.
